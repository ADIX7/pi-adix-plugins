# Powerbar Context Extra

Displays context window usage as a progress bar with a percentage and token counts.

```sh
pi install npm:@juanibiapina/pi-extension-settings
pi install npm:@juanibiapina/pi-powerbar
pi install npm:@adix7/powerbar-context-extra
```

Keep those packages in install order, then enable `context-usage-extra` on either side of Powerbar via `/extension-settings`.
